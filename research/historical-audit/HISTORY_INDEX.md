## Gaps, duplicate handling and reproducibility

- **2026-10-20:** The queried main-branch commit history for `docs/index.html` contains October 19 and October 21 publication commits but no October 20 commit. **Observed absence in the publication history only**; a failed run or historical site outage is unverified. Investigate GitHub Actions jobs, run summaries and any nonstandard publication path before assigning a root cause.
- **Multiple commits:** Query all commits touching the file, not only the first match. Prefer the latest publication snapshot **for the same edition date** and annotate earlier versions or corrections. This 30-edition window yielded one canonical commit per date. Other historical periods can contain republications (for example July 22), so do not generalize the absence of duplicates.
- **Build vs commit:** The local time above comes from embedded `<meta name="build">`; the commit SHA is the immutable identity of the archived file. The blob hash is the Git object identity, not a separate SHA-256 checksum.
- **Bounded storage:** No HTML articles, candidate pools, scraped paywalled text, model reasoning or secrets are copied into this index. The GitHub links are the archive. Pinned commits may lose remote reachability if branch history is rewritten; retention is a repository policy consideration rather than a guarantee.
